#### 🚨 `01` RoadSOS — Autonomous Kinematic Collision Engine
> **Mobile Sensing → Real-time Telemetry Pipeline → Anomaly Triangulation → Emergency Dispatch**

```text
[IMU SENSORS] ──> [3-AXIS ACCEL / GYRO] ──> [ML ANOMALY FILTER] ──> [INCIDENT CLASSIFIER] ──> [AUTOMATED DISPATCH]
```

- **The Problem:** Traditional crash alert systems rely on expensive proprietary in-vehicle hardware. Millions of motorists have smartphones with high-grade inertial measurement units (IMUs) that sit completely idle during catastrophic impact.
- **The Architecture:** Ingests continuous background accelerometer and gyroscope vectors from mobile telemetry, applies pattern filtering to isolate true impact deceleration from dropped phones or sudden braking, and coordinates backend emergency location dispatch.
- **Stack:** `Python` · `JavaScript` · `Node.js` · `C++` · `Git` · `GitHub`
- **Execution Status:** `Active build // continuous telemetry refinement`

---

#### ⚡ `02` GridSenti — High-Impedance Feeder Fault Detection
> **Electrical Waveform Telemetry → Heuristic Arc Analysis → High-Impedance Classification**

```text
[DISTRIBUTION FEEDER] ──> [CURRENT / VOLTAGE WAVES] ──> [HEURISTIC FILTER] ──> [ML FAULT MODEL] ──> [TRIP TELEMETRY]
```

- **The Problem:** High-Impedance Faults (HIFs) in electrical distribution networks occur when downed conductors contact poorly conducting surfaces (asphalt, dry soil, sand). The fault current is too low to trip conventional overcurrent relays, yet dangerous enough to cause electric shock and wildland fires.
- **The Architecture:** Pairs continuous current/voltage telemetry data with non-linear feature extraction, harmonic distortion analysis, and ML classification algorithms to flag subtle high-impedance anomalies before catastrophic flashovers occur.
- **Stack:** `Python` · `C` · `C++` · `Git` · `GitHub`
- **Execution Status:** `Exploratory modeling // mathematical simulation & verification`

- **The Problem:** Campus hiring pipelines in tier-1 institutions are notorious for fragile spreadsheet dependencies, lost application updates, conflicting interview schedules, and zero tamper-proof audit trails.
